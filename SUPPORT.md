# Support

- **Bugs, feature requests, and documentation problems:** open a GitHub Issue using the templates. Include enough detail to reproduce.
- **Questions and ideas:** use GitHub Discussions if enabled, or email **{{CONTACT_EMAIL}}**.
- **Security issues:** do _not_ open an issue. See [`SECURITY.md`](./SECURITY.md).
- **Contributions:** open a Pull Request. Read [`CONTRIBUTING.md`](./CONTRIBUTING.md) first.

## Expectations

Responses are best effort. Pull requests should pass CI and follow `.github/PULL_REQUEST_TEMPLATE.md`.

> Template note: adjust response times and channels to what you can actually commit to.
